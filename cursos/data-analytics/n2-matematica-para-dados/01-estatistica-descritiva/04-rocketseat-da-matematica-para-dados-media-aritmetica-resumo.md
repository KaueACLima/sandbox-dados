# 📌 Medidas de Tendência Central: Média Aritmética

### 1. Conceito Central
**Medidas de tendência central** são medidas que resumem um conjunto de dados, apontando um valor central, típico ou mais frequente daquele conjunto. As três principais são **média, moda e mediana**, e esta aula foca na primeira delas: a **média aritmética**, definida como a soma de todos os valores de um conjunto dividida pela quantidade de valores somados.

### 2. Pontos-chave e Sintaxe
- Fórmula: somatório de todos os valores, dividido pela quantidade de valores somados (se somou 2 números, divide por 2; se somou 7, divide por 7).
- Exemplo didático simples: nota 4 na primeira prova + nota 6 na segunda prova → (4+6)/2 = 5.
- A média serve para visualizar rapidamente um "valor típico" de um conjunto de dados e comunicar isso de forma simples para outras pessoas (chefe, supervisor, colega), sem precisar expor o conjunto bruto inteiro.
- A média é aplicável a diversos contextos de negócio: média de salário, média de quantidade de funcionários, média de acessos, média de faturamento.
- ⚠️ **Ponto de atenção:** o professor adianta que a média pode ser **enganosa/traiçoeira** em certos cenários, e que as próximas aulas vão apresentar outras medidas que trazem uma análise mais precisa e confiável — ou seja, a média sozinha não é 100% confiável para toda situação.

#### Exemplo prático resolvido
```
# Acessos diários a um site ao longo de uma semana (7 valores):
100, 130, 180, 200, 230, 250, 300

# Soma de todos os valores:
100 + 130 + 180 + 200 + 230 + 250 + 300 = 1390

# Divisão pela quantidade de valores (7):
1390 / 7 = 198,57

# Resultado: a média de acessos diários na semana é de ~198,57 acessos/dia
```

### 3. 🧠 Raciocínio Lógico
- Conta-se quantos valores existem no conjunto de dados (nesse caso, 7 dias de acesso).
- Somam-se todos os valores do conjunto.
- Divide-se a soma total pela quantidade de valores contados no primeiro passo.
- O resultado é um único número que representa, de forma resumida, o comportamento típico daquele conjunto — permitindo gerar um relatório básico (ex: "a média de acessos é de quase 200 por dia") sem precisar listar os 7 valores individuais.
