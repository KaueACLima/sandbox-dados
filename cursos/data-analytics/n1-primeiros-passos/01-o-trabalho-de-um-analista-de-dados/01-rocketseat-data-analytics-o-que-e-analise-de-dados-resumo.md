# 📌 O que é Análise de Dados

### 1. Conceito Central
Análise de dados é a atividade de avaliar registros históricos de uma empresa para extrair insights que orientem decisões de negócio — uma camada anterior e diferente de predição ou machine learning, que ficam a cargo de outras funções do campo de dados (cientista de dados, engenheiro de dados). O analista de dados olha para o que já aconteceu (ex: resultado de vendas de um mês) e devolve ao executivo uma explicação do porquê — por exemplo, por que houve queda nas vendas. O valor estratégico disso vem do fato de que dados bem analisados permitem às empresas prever comportamento, otimizar operação e, no fim, maximizar lucro — seja recomendando conteúdo em uma rede social, avaliando risco de crédito em um banco, ou ajustando produção em uma indústria de moda.

### 2. Pontos-chave e Sintaxe
- O analista de dados trabalha com **dados históricos** (o que já ocorreu), não com previsão — essa é a linha que separa a análise de dados da ciência de dados.
- O fluxo típico do analista: avaliar dado histórico → identificar padrão/anomalia → devolver **insight** para quem toma decisão (o executivo).
- Exemplos de uso real de dados citados na aula: redes sociais rastreando engajamento (tempo de visualização, curtidas, comentários) para recomendar conteúdo e vender mais publicidade; bancos usando histórico de comportamento para detecção de fraude e análise de crédito; agro usando dados de clima e colheita para otimizar plantio; moda/fast fashion ajustando produção conforme desempenho de venda por peça, evitando estoque parado.
- O **porte da empresa** (faturamento anual) influencia o nível de maturidade analítica: empresas pequenas (até ~15 milhões) tendem a ter menos análise de dados que empresas maiores, porque coletar e armazenar dado tem custo real.
- 💡 **Regra prática citada na aula:** cerca de 80% do trabalho de um profissional de dados é tratar e verificar dado (coleta, limpeza, validação, análise exploratória); os 20% restantes são a parte "vistosa" (IA, predição). Vale gravar isso como expectativa realista da rotina.
- Desafios da área: garantir qualidade/confiabilidade do dado coletado; lidar com grande volume (Big Data); cumprir exigências de proteção e privacidade (LGPD — Lei Geral de Proteção de Dados); necessidade de atualização técnica constante (a aula cita a virada recente de "machine learning" para "agentes de IA" como exemplo de mudança rápida).
- Oportunidades da área: alta demanda por profissionais qualificados; possibilidade de atuação em praticamente qualquer setor (tecnologia, saúde, agro, petróleo, mídia, varejo); salários competitivos e trajetória de carreira (analista → cientista → engenheiro de dados, entre outras ramificações).

### 3. 🧭 Implicações Práticas
- Análise de dados não é exclusividade de empresa de tecnologia — qualquer setor que queira competir por lucro precisa de alguém tratando e interpretando seus dados.
- Pensar em exemplos de uso por segmento (o desafio proposto no fim da aula) é prática direta para portfólio e estudos de caso futuros — vale já começar a anotar ideias.
- Antes de "aprender a ferramenta" (Python, SQL etc.), vale internalizar que boa parte do trabalho real é tratamento e verificação de dado — isso recalibra a expectativa de rotina do analista júnior.
