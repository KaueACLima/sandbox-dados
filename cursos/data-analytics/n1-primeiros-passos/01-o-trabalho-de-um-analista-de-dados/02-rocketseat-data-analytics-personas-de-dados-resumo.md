# 📌 Personas de Dados: Analista, Cientista e Engenheiro

### 1. Conceito Central
O campo de dados se organiza em três personas principais — analista, cientista e engenheiro de dados — que se distribuem num espectro entre a camada de negócio e a camada técnica/dado bruto. O analista de dados fica mais próximo do negócio: coleta, limpa e trata dados com o objetivo de responder perguntas rápidas de decisão (análises diagnósticas e descritivas). O cientista de dados avança para análises mais complexas, de predição e prescrição — olhando para o que tende a acontecer no futuro e o que fazer para influenciar esse cenário. O engenheiro de dados fica na ponta mais técnica, responsável por estruturar e otimizar bancos de dados para que analista e cientista consigam trabalhar com dado confiável e performático. Nenhuma dessas três camadas é hierarquicamente "melhor" que a outra — são especializações diferentes, com dificuldades próprias, e os limites entre elas ainda são fluidos porque o mercado de dados é recente e está em formação.

### 2. Pontos-chave e Sintaxe
- **Analista de dados:** trabalha mais perto da camada de negócio; faz análises diagnósticas (por que algo aconteceu); ferramentas típicas citadas: Excel, SQL, Power BI e Python.
- **Cientista de dados:** faz análises preditivas (o que tende a acontecer) e prescritivas (o que fazer diante disso); depende muito mais de Python, porque esse tipo de análise é inviável em Excel.
- **Engenheiro de dados:** foca em estruturar e otimizar banco de dados para uso de analistas e cientistas; não faz a análise em si.
- ⚠️ **Ponto de atenção:** os limites entre essas três funções são voláteis — o surgimento recente de agentes de IA, por exemplo, gerou uma discussão em aberto sobre se esse escopo pertence ao engenheiro ou ao cientista de dados. É comum uma mesma pessoa acumular tarefas de mais de uma persona na prática.
- Faixas salariais citadas no Brasil, por senioridade (júnior → sênior):
  - Analista de dados: ~R$3.500–5.000 (júnior) até ~R$8.000–12.000 (sênior).
  - Cientista de dados: ~R$6.500–8.000 (júnior), com faixa sênior próxima à do engenheiro.
  - Engenheiro de dados: faixa salarial próxima à do cientista; sênior pode chegar a ~R$17.000–18.000.
- 💡 **Observação prática:** raramente se contrata cientista ou engenheiro de dados júnior sem passagem prévia por análise de dados — a persona de analista costuma ser a porta de entrada da carreira, inclusive porque há poucos estágios específicos de ciência de dados.
- Transição de carreira facilitada: quem já tem conhecimento de negócio (ex: ex-analista de negócios de banco) carrega uma vantagem real, porque esse domínio costuma ser o ponto fraco de quem vem só da parte técnica.
- A formação é **agnóstica de ferramenta**: o conceito de análise importa mais que a ferramenta específica (Python vs. Excel, Power BI vs. Looker Studio vs. Tableau) — dominar a lógica de uma permite migrar entre as outras com ajuste mínimo.
- Conhecimentos técnicos citados como base da formação: estatística, modelagem de dados e machine learning (em nível introdutório).

### 3. 🧭 Implicações Práticas
- Vale já decidir mentalmente em qual das três personas focar o estudo e o portfólio — mesmo sabendo que os limites são fluidos, isso orienta que ferramentas aprofundar primeiro.
- Quem vem de outra área de negócio (como o caso de front-end aqui) pode usar esse repertório prévio como diferencial, em vez de vê-lo como irrelevante para a transição.
